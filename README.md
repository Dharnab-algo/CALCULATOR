**[Live Demo](https://dharnab-algo.github.io/CALCULATOR/)**

## Preview



![Glow Calc Screenshot](screenshot.png)



## Features

- **Glowing digital display** with a pop animation on every update
- **Ripple effect** on button press for tactile feedback
- **Pulse animation** on the equals button
- **Shake animation on errors**, such as division by zero
- **Full keyboard support** for faster input
- **Responsive layout** that works on both desktop and mobile

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `0` - `9` | Enter digits |
| `+` `-` `*` `/` | Operators |
| `Enter` | Calculate result |
| `Backspace` | Delete last digit |
| `Esc` | Clear everything |

## Tech Stack

- **HTML5** for page structure
- **CSS3** for glassmorphism, gradients, and keyframe animations
- **JavaScript (ES6)** for calculator logic and event handling

## Getting Started

**Run locally**

```bash
git clone https://github.com/Dharnab-algo/CALCULATOR.git
cd CALCULATOR
```

Then open `index.html` in any modern browser. No build step or installation is required.

**Deploy with GitHub Pages**

1. Go to **Settings → Pages**
2. Select the `main` branch as the source
3. Your site will be live at `https://<username>.github.io/CALCULATOR/`
